## Title
Space Memory Card Game

## Description
A memory card game which player should remember which cards have not been clicked to win the game. This project implements react basic and hooks such as useEffect to fetch images of space objects.

## Technologies
- HTML: structure
- React JS: functional and structure
- CSS: layout and styling
- Netlify: deploy project
